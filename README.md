# ছাত্র সমিতি — Android v4

এই project-এ Firebase Realtime Database v4 web app-টি Android WebView app হিসেবে রাখা হয়েছে।

## APK build
Android Studio-তে এই project folder open করুন।
তারপর:
Build → Build App Bundle(s) / APK(s) → Build APK(s)

APK সাধারণত:
app/build/outputs/apk/debug/app-debug.apk

প্রথম build-এর সময় Android Studio প্রয়োজনীয় Gradle/Android dependencies ডাউনলোড করবে।
